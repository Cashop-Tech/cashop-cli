# config - 配置管理

配置文件位置：`~/.cashop-console/config.json`

## 命令

```bash
# 设置配置项
cashop-console config set <key> <value>
cashop-console config set env stable
cashop-console config set defaultSite JP

# 获取配置项
cashop-console config get <key>
cashop-console config get env

# 列出所有配置
cashop-console config list
```
